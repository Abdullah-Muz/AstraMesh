## 2. Analysis columns

- **problem:** A tutorial and survey framework for analysing linear consensus algorithms on networks.
  - It covers convergence, the decision value (average or weighted average), and speed, under directed graphs, switching topologies and time delays.
  - It links consensus to flocking, sensor fusion, formation control and other applications (Abstract; Sec. 1, pp.1-6).
  - It is not a task-allocation or scheduling paper.
- **agent_info:**
  - Each agent holds a scalar (or vector) state x_i with integrator dynamics x_i' = u_i, or x_i(k+1) = x_i(k) + u_i(k) in discrete time.
  - Agents exchange states only with graph neighbours N_i (Sec. 2, eq. 7 on p.7; eq. 15 on p.10). Fig. 1 (p.3) draws the same protocol two ways: (a) a digraph of integrator agents, (b) a block diagram with identical blocks P(s) = 1/s, Laplacian feedback L and an input bias b.
  - In the formation section, agents are identical LTI vehicles x_i' = A x_i + B u_i that sense relative states z_ij = C2(x_i - x_j) (Sec. 4.1, p.19, eqs. 38-41).
- **networking_assumptions:**
  - **Fixed digraph:** consensus holds if the digraph is strongly connected, or under the weaker condition that a directed spanning tree exists (Remark 1). Average consensus additionally requires a balanced digraph (Thm 1, pp.9-10; Thm 2, p.11). Discrete-time steps must satisfy 0 < eps < 1/Delta, where Delta is the maximum degree (Lemma 3, Remark 3, Thm 2, pp.10-11). Lemma 3 allows eps in (0, 1/Delta] for stochasticity, but primitivity (needed for convergence) requires the strict inequality; Remark 3 gives a directed-cycle counterexample at eps = 1/Delta.
  - **Disconnected digraph (partition):** Lemma 2 (p.9) states that a digraph with c ≥ 1 strongly connected components has rank(L) = n - c, i.e. one zero eigenvalue per component. The text gives no protocol or result for reconciling components after a partition heals.
  - **Switching topology:** if every graph in the finite set Γ is a balanced, strongly connected digraph (or connected undirected graph), average consensus holds for any arbitrary switching signal, with convergence speed ≥ λ2* = min_k λ2(G_k) and Φ(δ) = δᵀδ as a common Lyapunov function (Thm 5, p.16). This is a convergence-speed bound, not a constraint on the switching rate.
  - **Joint connectivity:** for discrete-time switching x_{k+1} = P_{s_k} x_k over undirected graphs with n self-loops, alignment holds if the union of graphs over each interval [j, jN) is connected ("periodically connected", Thm 6, Jadbabaie et al., p.17), or if the union over [k0, ∞) is connected ("ultimately connected", defined p.17, Thm 7, Moreau, p.18). Under the Jadbabaie Perron matrices (I+D)^-1(I+A) the group decision is "an undetermined quantity in the convex hull of all initial states" (p.17), not the average; Remark 7 (p.17) says using I - εL with 0 < ε < 1/(1 + max_k Δ(G_k)) resolves this. No convergence rate is given for Thm 6-7 (p.18 notes Moreau's proof gives no performance measure).
  - **Delays:** only a uniform one-hop delay τ is analysed, with the delay applied to both terms, x_i' = Σ a_ij (x_j(t-τ) - x_i(t-τ)) (eq. 31, p.15), proposed for undirected graphs. Average consensus holds iff 0 ≤ τ < π/(2λ_n) (Thm 4, p.16; proof deferred to [70]); since λ_n < 2Δ, τ < π/(4Δ) is sufficient (p.16). Remark 6 (p.15): the variant with only x_j delayed (eq. 32) does not preserve the average for a general graph, and for (31) the average is invariant on balanced digraphs with 0-1 weights. A transfer-function form H(s) = (I_n + (1/s) e^{-sτ} L)^-1 with a Nyquist test is given (eq. 33, p.16).
  - Packet loss and asynchrony are mentioned only as causes of switching topology (Sec. 3, p.16), and packet loss again as a real-world communication limitation in Sec. 4 (p.18, citing [83, 33]); neither is analysed. Asynchronous consensus with performance guarantees is called "currently an open problem" (Sec. 3, p.17).
- **physics:**
  - No orbital or environmental physics.
  - The only dynamics are generic integrator and LTI vehicle models, plus a double integrator with time delay e^{-sT}/s^2 in the formation example (Sec. 5.2, p.21).
- **fault_model:**
  - Link and node failures are modelled only as topology switching (Abstract; Sec. 3, p.16).
  - Non-cooperating agents are discussed informally: one agent holding its state blocks f-consensus, and a disconnecting coalition prevents agreement (Sec. 1.2, p.4).
  - Adversarial agents are explicitly out of scope (p.4).
- **safety_model:** not stated in the text. Collision avoidance in flocking is mentioned only as related work (p.6).
- **method:** The core is the Laplacian protocol.
  - Continuous time: x_i' = Σ_{j∈N_i} a_ij (x_j - x_i), i.e. x' = -Lx with L = D - A (eqs. 7-9, p.7).
  - Discrete time: x(k+1) = P x(k) with the Perron matrix P = I - εL (eqs. 15-16, p.10).
  - Convergence speed is bounded by the algebraic connectivity λ2 (Thm 3, Cor. 1-2, pp.12-13).
  - Table 2 (p.15) compares three Laplacian forms with their Perron matrices and step sizes: D-A with I - εL, ε in (0, Δ^-1); I - D^-1 A (Fax and Murray) with D^-1 A, ε = 1; and I - (I+D)^-1(I+A) (Jadbabaie et al.) with (I+D)^-1(I+A), ε = 1. Only D-A gives average consensus (Sec. 2.6, p.15), and only the first and third rows guarantee discrete-time stability for all connected networks (p.15; Example 2, p.14, shows D^-1 A failing on a bipartite graph).
  - Formation stability is reduced to n single-vehicle problems scaled by the eigenvalues of the normalized Laplacian (Thm 8-9, Fax and Murray, p.20). Fig. 3 (p.18) shows the loop: I_n ⊗ K(s), then I_n ⊗ P(s), with consensus feedback L ⊗ I_m.
- **baselines:**
  - No algorithmic baselines.
  - The simulations compare topologies: a small-world graph against regular lattices with k=2 and k=10 nearest neighbours (Sec. 5.1, p.20; Fig. 4, p.21). Fig. 4 caption: (a) small-world, 300 links; (b) k=2 lattice, 300 links; (c) k=10 lattice, 1000 links; (d)-(f) the corresponding state trajectories for x_i(0) = i, n = 100.
- **metrics:**
  - Convergence speed through λ2. Example: the small-world graph converges about 22× faster than a lattice with the same number of links (300) (Sec. 5.1, p.20). Fig. 4 is consistent: (d) and (f) settle within about 4 s on a 0-10 s axis, while (e) (k=2 lattice) needs roughly 100 s on a 0-150 s axis. The text's panel letters disagree with the caption (it calls the 300-link lattice "(c)" and the 1000-link lattice "(e)"); the caption and plots are taken as authoritative here.
  - Delay margin (Thm 4).
  - Nyquist stability margins, about 8 dB and 45° before accounting for the formation (Sec. 5.2, p.21).
- **scale:**
  - n = 100 nodes in the consensus simulations (Sec. 5.1).
  - n = 20 graphs in Example 1 (p.8; Fig. 2, p.9): (a) a regular ring network with 80 links, λ2 = 0.48, λ_n = 6.24, Δ = 4; (b) a random proximity network with 65 links, λ2 = 0.25, λ_n = 9.37, Δ = 10.
  - A 6-vehicle formation graph (Fig. 5, p.22): (a) a directed interconnection graph on vehicles 1-6 with one dashed arc between 1 and 6; (b) the Nyquist plot of K(s)P(s) with 'o' marks for the Laplacian eigenvalues without the dashed arc and '×' marks with it. Per the text (p.21), the '×' formation is unstable.
  - A cited example: n = 1000 small-world vs. regular, λ2 ratio > 1500 (p.13).
- **key_limitations:**
  - Agents agree on continuous real-valued quantities, not on discrete assignments.
  - The delay results assume uniform, constant, one-hop delays.
  - Switching results need connectivity at every instant (Thm 5), or connectivity of graph unions over time (Thm 6-7) without a rate.
  - Asynchrony and packet loss are not analysed directly.
  - There is no fault or adversary model beyond topology change.
  - The Corollary 2 proof for balanced digraphs is omitted (Remark 4, p.13).
- **AstraMesh_overlap (cautious):**
  - Useful as background theory for any AstraMesh component that averages continuous shared state across the four satellites, e.g. a clock or estimate agreement. It gives the connectivity vocabulary needed to talk about intermittent crosslinks ("periodically/ultimately connected" unions of graphs).
  - It does **not** cover discrete task or observation assignment, non-uniform or variable latency, message loss, or partitions with conflicting state. It cannot serve as a baseline for the scheduling problem.
  - Its delay bound and connectivity conditions should not be assumed to carry over to CBBA-style discrete consensus.

## 3. replication_priority

**Low.** It is a theory survey with no allocation algorithm or benchmark, so there is nothing to replicate as a baseline. Cite it for definitions and connectivity and delay conditions only.
