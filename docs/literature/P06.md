## 2. Analysis columns

- **problem:**
  - The paper addresses decentralized task allocation. N_t tasks go to N_u agents, each agent takes at most L_t tasks, the assignment must be conflict-free (each task to at most one agent), and the sum of the agents' local rewards is maximized (Eq. (1), Sec. II-A).
  - Exactly N_min = min{N_t, N_u·L_t} tasks must be assigned.
  - Scores c_ij(x_i, p_i) ≥ 0 may depend on the agent's path p_i.
  - Two cases:
    - **Single-assignment:** L_t = 1 with constant c_ij. This is solved by CBAA (Sec. III).
    - **Multi-assignment:** solved by CBBA (Sec. IV).
- **agent_info:**
  - **CBAA (Sec. III):**
    - Each agent stores x_i ∈ {0,1}^{N_t} (its own assignment) and y_i (winning bids).
    - It sends only y_i to its neighbours (Alg. 2, lines 1-2).
    - z_{i,J_i} is computed locally for the agent's own selected task only (Alg. 2, line 5).
  - **CBBA (Sec. IV-A/B):** each agent stores five things:
    - y_i ∈ R_+^{N_t}: winning bids
    - z_i ∈ I^{N_t}: winning agents
    - b_i: the bundle, at most L_t long, in the order tasks were added
    - p_i: the path, at most L_t long, in execution order
    - s_i ∈ R^{N_u}: the time stamp of the last information update from each agent
  - CBBA communicates the three vectors y_i, z_i, s_i (Sec. IV-B, "three vectors are communicated for consensus").
  - Bundles, paths and scores are not exchanged. Situational awareness (SA) is not exchanged either: each agent scores tasks from its own SA (Sec. V-D).
- **networking_assumptions:**
  - **Graph model.** The network is an undirected graph G(τ) with a symmetric adjacency matrix and self-loops g_ii = 1 (Sec. III-B). One iteration is one run of phase 1 plus one run of phase 2. Agents' iteration counts and periods may differ (Sec. III-A).
  - **Analysis setting.** The analysis assumes *synchronized* conflict resolution, meaning every agent's phase 2 of iteration t happens at the same time, over a *static, connected* network with diameter D (Eq. (19), Sec. V-B). The convergence bound is then N_min·D iterations (Thm. 1). It is not 2·N_t·D.
  - **Dynamic networks (synchronous phase 2).** Convergence holds if there is a ρ < ∞ such that the union of the graphs over ρ consecutive iterations is "fully connected" for all t. The bound is then ρ·N_min (Sec. V-C). This is argued in prose with a citation to [53], not proven as a numbered theorem.
  - **Asynchrony.** Asynchrony is "modeled as a dynamic network with synchronized conflict resolution". If an agent "eventually communicates with its neighbor", convergence happens in finite time, with no bound given (Sec. V-C, informal).
  - **Message delay** is not modelled.
  - **Message loss** is not stated. The convergence argument under inconsistent SA explicitly assumes y, z, s are "communicated error-free" (Sec. V-D).
  - **Clock synchronization** for the τ_r time stamps is not stated.
- **physics:**
  - The only physical model is a 2-D plane (W = 2 km) with straight-line travel at 40 m/s.
  - Scoring uses the time-discounted reward S = Σ λ_j^{τ_j} c̄_j (Eq. (11)), with c̄_j = 1 and λ = 0.95 s⁻¹ (Sec. VII-A).
  - There are no vehicle dynamics, orbits, energy or sensing physics.
- **fault_model:**
  - The only perturbation studied is inconsistent SA: agents estimate task positions with Gaussian noise of standard deviation 0.01W-0.2W (Sec. VII-A).
  - Time-varying topology is discussed (Sec. V-C).
  - Agent failure, Byzantine behaviour, message loss and corruption, and partitions that never heal are not addressed.
- **safety_model:**
  - None. The only notion of correctness is a conflict-free, feasible assignment (constraints of Eq. (1); the convergence definition, Eqs. (20)-(21)).
- **method:**
  - The method is a market-based auction (greedy bundle building, Alg. 3) combined with consensus on winning bids, winning agents and timestamps (Table I, Eqs. (5)-(6)).
  - Each agent builds one bundle by greedily inserting the task with the best marginal gain, at its best path position (Eqs. (3)-(4)).
  - When an agent is outbid, it releases that task and every task added after it (Eq. (6)).
  - With diminishing marginal gain (DMG) scores, CBBA reproduces the centralized sequential greedy algorithm (SGA, Alg. 4; Thm. 1).
  - Lemma 4 gives a modified score, min{c°_ij(t), c_ij(t−1)}, that guarantees conflict-free convergence without DMG.
- **baselines:**
  - Implicit coordination [8] with perfect information is used as the "optimal" reference for the optimality gap (Sec. VII-A).
  - Prim Allocation (PA) [33] is a centralized sequential auction (Sec. VII-B).
  - Iterative CBAA (ICBAA) runs CBAA repeatedly until all tasks are assigned (Sec. VII-B).
- **metrics:**
  - Convergence time in iteration steps (Figs. 1 and 4)
  - Optimality gap in % against implicit coordination (Fig. 2)
  - Average SA error Ē_SA (Eq. (45))
  - Total distance travelled (Fig. 3)
  - Theoretical metrics: the convergence bound N_min·D, and 50% optimality (SOPT ≤ 2·CBAA, MOPT ≤ 2·CBBA)
- **scale:**
  - **Figs. 1-2:** N_u = N_t from about 1 to 20. Networks are random spanning trees plus extra random links.
  - **Figs. 3-4:** N_u = 5, N_t up to 40, L_t = N_t. Figure 4 assumes a fully connected network (D = 1).
  - The number of Monte Carlo runs is not stated.
- **key_limitations:**
  - **Guarantees rest on idealised assumptions:**
    - The guarantees need DMG scores, synchronized phase 2 and a static network (Thm. 1). The 50% bound also needs accurate SA (Lemma 5, Thm. 2).
    - The dynamic and asynchronous cases are argued only informally, with no bound for asynchrony.
    - Message loss, delay and clock offsets are not modelled. The robustness argument assumes y, z, s arrive error-free (Sec. V-D).
  - **Gaps in the specification:**
    - Termination detection is not specified: convergence T_C is defined globally, after the fact.
    - Tie-breaking is only "resolved in a systematic way", with lexicographic order given as an example.
    - Updating the path after a release is not spelled out.
  - **Limits of the experiments:**
    - DMG excludes synergistic rewards (Sec. IV-C).
    - The time-discounted reward does not satisfy the stricter conditions of Lemma 3.
    - The experiments are abstract 2-D, small scale, with no dynamic task arrival.
- **AstraMesh_overlap:** cautious; this is my reading.
  - **Direct overlap.** This paper defines the algorithm that baseline B3 must reproduce. The conflict-resolution state it exchanges is y, z, s per agent. AstraMesh's message envelope (sender, seq, expiry, plan-version) is extra and not part of CBBA.
  - **Untested conditions.** With 4 agents, D ≤ 3, but the paper's guarantees assume synchronous, lossless exchange on a static (or ρ-jointly-connected) graph. AstraMesh's 1 s application delay, 1% Bernoulli loss and possible partitions fall outside what the paper proves. By the reasoning in Sec. V-C, a lost message can be treated as a temporary link outage. That supports finite-time convergence only if links recur, and the paper gives no bound for that case.
  - **Two options for B3:**
    - Run phase 2 in synchronized rounds and record that the theory's assumptions are violated by loss and delay.
    - Or call the baseline "CBBA-inspired" if it changes the timestamp or round semantics.
  - **DMG check.** Whether the ionospheric observation scores are DMG must be checked. Visibility windows, required waiting and value that is not monotone in time could break DMG, and with it the SGA equivalence and the 50% bound. Lemma 4's min-filter gives conflict-free convergence without DMG, but only in the synchronized, static setting.

## 3. CBBA reimplementation specification (faithful to the paper)

Notation follows the paper:
- I = {1..N_u} is the set of agents and J = {1..N_t} the set of tasks.
- ∅ is the empty task, or "none" for a winner.
- ⊕_n inserts a list after the n-th element; ⊕_end appends.

### (a) Per-agent state (Sec. III-A, IV-A, IV-B)

| Symbol | Type | Meaning | Init |
|---|---|---|---|
| y_i | R_+^{N_t} | winning-bid list: agent i's latest estimate of the highest bid on each task | 0 (CBAA: "initialized as zero vectors"; CBBA: no initial value given in the paper, so 0 is assumed) |
| z_i | (I ∪ {∅})^{N_t} | winning-agent list | ∅ (assumed, not stated) |
| b_i | (J ∪ {∅})^{L_t} | bundle, in the order tasks were added | empty |
| p_i | (J ∪ {∅})^{L_t} | path, in execution order; S_i^{p_i} is the total reward along it | empty, with S_i^{{∅}} = 0 (stated) |
| s_i | R^{N_u} | s_ik is the time stamp of the last information update from agent k | not stated |
| x_i | {0,1}^{N_t} | used in CBAA only, where it is the agent's own assignment; in CBBA it is represented by b_i | 0 |
| G(τ) | adjacency matrix | g_ik(τ) = 1 if i and k are linked; g_ii = 1 | given |

- **Messages.** In CBBA a message carries (y_k, z_k, s_k). In CBAA it carries y_k only.
- **Iteration.** An iteration t is phase 1 followed by phase 2.

### (b) Phase 1

**CBAA (Alg. 1, single assignment, constant scores c_ij ≥ 0):**
1. Set x_i(t) = x_i(t−1) and y_i(t) = y_i(t−1).
2. If Σ_j x_ij(t) = 0:
   - Compute h_ij = I(c_ij > y_ij) for all j (Eq. (2)). The inequality is **strict**.
   - If h_i ≠ 0:
     - Set J_i = argmax_j h_ij·c_ij.
     - Set x_{i,J_i} = 1 and y_{i,J_i} = c_{i,J_i}.
3. If the agent already holds a task, phase 1 is skipped.

**CBBA (Alg. 3, `BUILD BUNDLE`):**
1. Copy y_i, z_i, b_i, p_i from t−1.
2. While |b_i| < L_t:
   - **Marginal score (Eq. (3), line 7).** For j ∉ b_i, c_ij[b_i] = max_{n ≤ |p_i|} S_i^{p_i ⊕_n {j}} − S_i^{p_i}. For j ∈ b_i, c_ij[b_i] = 0. That is, task j is tried at every insertion position, and the best gain is its bid.
     - Positions run over n ≤ |p_i|, where ⊕_n inserts after the n-th element. I read n = 0 as "insert at the front". The index range is printed as n ≤ |p_i|; the lower bound is not printed.
   - **Availability (line 8).** h_ij = I(c_ij > y_ij), strict, for all j.
   - **Selection (line 9).** J_i = argmax_j c_ij·h_ij.
   - **Insertion position (line 10).** n_{i,J_i} = argmax_n S_i^{p_i ⊕_n {J_i}}.
   - **Bookkeeping (lines 11-14):**
     - b_i ← b_i ⊕_end {J_i}
     - p_i ← p_i ⊕_{n_{i,J_i}} {J_i}
     - y_{i,J_i} ← c_{i,J_i}
     - z_{i,J_i} ← i
3. **Stopping.** The text after Eq. (4) says the recursion continues "until either |b_i| = L_t or until h_i = 0". Algorithm 3 as printed has only the `while |b_i| < L_t` guard. An implementer must add a break when h_i·c_i = 0 (UNSURE: printed omission, but the intent is clear from the text).
4. **Assumptions.** The paper assumes c_ij[b_i] ≥ 0, with equality only when j ∈ b_i (Sec. IV-A). A bid is the marginal score at the moment of insertion. It is stored in y and is not recomputed while the task remains in the bundle.
5. **Ties.** For J_i in phase 1 and z in phase 2, ties are "resolved in a systematic way. For example, a lexicographical tie-breaking heuristic based on the agent and the task identification numbers can be used" (Sec. III-B). The exact rule is UNSPECIFIED. For B3, choose one (for example, lowest task ID, then lowest agent ID) and document it. Table I itself uses strict inequalities on y and s.
6. **Bundle length.** |b_i| ≤ L_t and |p_i| ≤ L_t. With L_t = 1, CBBA gives the same solution as CBAA (Sec. IV-B, end).

### (c) Phase 2: consensus / conflict resolution (Sec. IV-B)

**Exchange.** Each agent sends (y_i, z_i, s_i) to its neighbours (g_ik = 1) and receives (y_k, z_k, s_k) from them.

**Timestamp rule (Eq. (5)), applied "each time a message is passed":**
- s_ik = τ_r if g_ik = 1, where τ_r is the message reception time.
- Otherwise, s_ik = max_{m: g_im = 1} s_mk.

So a direct neighbour's entry is set to the reception time. Every other agent's entry is the maximum over neighbours' time stamps for that agent. Points the paper does NOT state:
- whether s is updated before or after the Table I comparisons
- how s_ii is handled (g_ii = 1 would imply τ_r)
- the initial values of s
- what clock τ_r refers to, local or global

**Actions on task j by receiver i after a message from sender k:**
- **update:** y_ij = y_kj, z_ij = z_kj
- **reset:** y_ij = 0, z_ij = ∅
- **leave:** y_ij and z_ij unchanged. This is the default.

**Table I: action rule for agent i on task j, after communication with agent k.**
- I checked this table against a 220-dpi render of p. 917.
- m and n denote agents other than the ones named, and "none" means z = ∅.
- s_km is the sender's time stamp for agent m; s_im is the receiver's.

| # | Sender k thinks z_kj is | Receiver i thinks z_ij is | Receiver's action (default: leave) |
|---|---|---|---|
| 1 | k | i | if y_kj > y_ij → update |
| 2 | k | k | update |
| 3 | k | m ∉ {i,k} | if s_km > s_im or y_kj > y_ij → update |
| 4 | k | none | update |
| 5 | i | i | leave |
| 6 | i | k | reset |
| 7 | i | m ∉ {i,k} | if s_km > s_im → reset |
| 8 | i | none | leave |
| 9 | m ∉ {i,k} | i | if s_km > s_im and y_kj > y_ij → update |
| 10 | m ∉ {i,k} | k | if s_km > s_im → update; else → reset |
| 11 | m ∉ {i,k} | m | s_km > s_im → update (printed without "if"; read as a condition) |
| 12 | m ∉ {i,k} | n ∉ {i,k,m} | if s_km > s_im and s_kn > s_in → update; if s_km > s_im and y_kj > y_ij → update; if s_kn > s_in and s_im > s_km → reset |
| 13 | m ∉ {i,k} | none | if s_km > s_im → update |
| 14 | none | i | leave |
| 15 | none | k | update |
| 16 | none | m ∉ {i,k} | if s_km > s_im → update |
| 17 | none | none | leave |

How to apply the table:
- Row 12 has three sub-conditions, checked in the printed order. Whether they are meant to be mutually exclusive or first-match is not stated. As printed, they cannot conflict: the two "update" lines both need s_km > s_im, and the "reset" line needs s_im > s_km. If none holds, the action is leave.
- With several neighbours in one round, the order in which messages are processed is not specified (UNSURE).
- **CBAA as a special case:** apply the receiver rules ignoring s_k, and only for the receiver's selected task. Every incoming y_k is valid if it is larger (Sec. IV-B, final paragraph). The literal CBAA Algorithm 2 is:
  - y_ij = max_k g_ik·y_kj for all j
  - z_{i,J_i} = argmax_k g_ik·y_{k,J_i}
  - if z_{i,J_i} ≠ i, then x_{i,J_i} = 0

### (d) Bundle release after an outbid or reset (Eq. (6))

"If a bid is changed by the decision rules in Table I", the agent checks whether any updated or reset task is in its bundle. If so:
- Let n̄_i = min{n : z_{i,b_in} ≠ i}. This is the first bundle position whose task the agent no longer wins.
- Set y_{i,b_in} = 0 and z_{i,b_in} = ∅ for all n > n̄_i. This resets the bids for tasks added **after** the outbid task, because their marginal scores are no longer valid.
- Set b_in = ∅ for all n ≥ n̄_i. This removes the outbid task and every later task from the bundle.
- The outbid task itself keeps the y/z values it just received through update or reset; it is not reset by Eq. (6).
- The paper does not say how p_i is updated. Equation (4) implies the path is determined by the bundle, so I assume p_i is rebuilt to hold only the remaining bundle tasks in their positions (UNSURE: not stated).
- The agent then returns to phase 1.

### (e) DMG and which guarantees depend on it

**DMG (Eq. (7)):** c_ij[b_i] ≥ c_ij[b_i ⊕_end b] for all b_i, b, j with ((b_i ⊕_end b) ⊕_end {j}) ∈ (J ∪ {∅})^{L_t}.
- In words, a task's marginal value never increases when other tasks are added to the bundle before it.
- Equation (8) restates this in path-score form.
- Under DMG, bids along a bundle never increase: y_{i,b_in} ≥ y_{i,b_im} for n ≤ m (Eq. (9)).
- The time-discounted reward of Eq. (11) is DMG, by the triangle inequality (Eq. (12)).

Results that **need DMG**:
- **Lemma 1 and Lemma 2.** These assume synchronous phase 2, a static network of diameter D, and DMG. Every agent agrees on the first n SGA assignments by iteration nD.
- **Theorem 1 (Convergence of CBBA).** It assumes a DMG score, a synchronized conflict-resolution phase and a static network with diameter D. Then:
  1. CBBA produces the same solution as SGA (Alg. 4), with y and z shared across the fleet (Eq. (31)).
  2. T_C ≤ N_min·D.

  The paper notes that convergence is usually much earlier.
- **Theorem 2 (CBBA performance bound).** It assumes accurate SA, DMG scoring and nonnegative scores. Then MOPT ≤ 2·CBBA, which is 50% optimality. The proof (App. C) relies on CBBA = SGA.
- **Lemma 5 (CBAA bound).** It assumes accurate SA. Then SOPT ≤ 2·CBAA. The printed lemma reads "CBBA guarantees 50% optimality"; this looks like a typo for CBAA. Single assignment with constant c_ij needs no separate DMG assumption.

Results that **do not need DMG**:
- **Lemma 3.** If scores are non-increasing over iterations (Eq. (32)) and the agent ranking per task is preserved over time (Eq. (33)), CBBA converges to a conflict-free assignment in N_min·D iterations. This holds on a static network with diameter D; synchronous operation is implied by the proof. The paper notes that these conditions are restrictive and that Eq. (11) does not generally satisfy them.
- **Lemma 4.** It assumes synchronized conflict resolution and a static network of diameter D, with any scores. Using the modified score c_ij(t) = min{c°_ij(t), c_ij(t−1)} (Eq. (34)) gives conflict-free convergence within N_min·D. There is no SGA equivalence and no optimality bound.

Results stated only in prose (**no theorem**):
- **Dynamic network, synchronous phase 2:** if the union of graphs over every window of ρ iterations is fully connected, the bound is ρ·N_min (Sec. V-C).
- **Asynchronous phase 2:** finite-time convergence if agents eventually communicate; no bound is given (Sec. V-C).
- **Inconsistent SA:** convergence to a feasible assignment is unaffected, provided y, z, s are communicated error-free. Performance may degrade (Sec. V-D).

**Correction to the brief:** the paper's bound is **N_min·D** (Thm. 1 and Lemmas 3-4), where N_min = min{N_t, N_u·L_t}. It is not 2·N_t·D. Section VII-B says a single CBAA "can take up to min{N_u, N_t}D iterations by Theorem 1".

### (f) Termination criterion

- None is specified for agents to detect termination locally.
- Convergence is defined globally and after the fact. T_C is the smallest iteration after which the assignment never changes and satisfies the constraints of Eq. (1) (Eqs. (20)-(21)).
- The paper gives no stopping rule. A B3 implementation must add one, for example "no change in y, z, b for X rounds" or a round cap such as N_min·D. This should be labelled as an implementation addition.

## 4. replication_priority

**High.** This paper is the primary definition of the CBBA that baseline B3 claims to reproduce. Table I, Eqs. (3)-(6) and the DMG and synchrony assumptions behind Theorem 1 must be implemented and documented exactly. Otherwise B3 has to be labelled "CBBA-inspired".
